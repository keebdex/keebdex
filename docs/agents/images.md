# Images

Feature reference for Keebdex agents; project-wide rules live in [AGENTS.md](../../AGENTS.md).

- Use `NuxtImg` for optimized images where appropriate. The default image provider (`app/providers/cloudflare-images.ts`, registered as `cloudflare`, which overrides @nuxt/image's built-in Image Resizing provider of that name; it must stay the default because presets cannot set a provider) turns stored Cloudflare Images URLs of Keebdex's own account (`cloudflareImageBase` in `app/utils/image-info.ts`, which compares the URL's hash with `runtimeConfig.public.cloudflare.accountHash`; `…/<id>/public`, ids may contain slashes) into flexible variants (`…/<id>/w=<n>,fit=scale-down`, width rounded up to a fixed ladder) whenever `sizes` applies, and returns every other source unchanged, including images on other Cloudflare accounts (vendor sites), which answer flexible variants and `format=json` with a 403 until catalog-sync copies them over. Give images a preset from `nuxt.config.ts` (`square` for artisan colorway and sculpt grids, `cover` for keyset and keyboard grids and the keyboard page's derived designs, `thumb` for submission thumbnails) or a `sizes` of their own for other layouts (the keyset detail cover, the keyboard page's photo carousel and filmstrip, the marquee); preset sizes are measured shares of the viewport, so re-measure them when a grid's columns change. Grid and thumbnail images also take `loading="lazy"` and `decoding="async"`; the above-the-fold keyset detail cover and the keyboard page's first carousel photo load eagerly with `fetchpriority="high"` instead. Leave images captured by `SharedSnapshot` or opened in previews on the stored URL. Brand, maker, and profile logos (`logoUrl(key)` in `app/utils/logo.ts`, `${imgUrl}/logo/<key>.png`; server code passes its own `imgUrl` as the second argument) are fixed 500×500 files on R2, not Cloudflare Images, so they never get a preset. The `keebdex` bucket's CORS rule allows `GET`/`HEAD` from `https://keebdex.org`, `https://www.keebdex.org`, and `http://localhost:3000`, so captured images (`SharedSnapshot`, `captureScreenshot`) can include logos; another origin's capture drops them.
- Copied/downloaded images must not depend on the screen size. Render what is captured inside `SharedSnapshot` (off screen, client-only, rendered only while capturing, optional fixed `width`, waits for images) and call its exposed `capture()`; content with its own fixed size (the trading cards in `ArtisanColorwayCard`'s popup, see "Share card" in `docs/agents/artisan.md`) may be captured in place. Use the helpers in `app/utils/screenshot.ts`: `captureScreenshot`, `copyBlob` (pass the capture promise so the clipboard write stays in the click gesture, as Safari requires), `downloadBlob`, `shareBlob`/`canShareFiles`. Current users: the wishlist sheet, and `KeyboardVariantDrawer`, which captures `KeyboardVariantCard` at 48rem (its `SharedSpecList` lays out by container width, so the image keeps three columns on any screen).
